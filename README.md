# Local AI Infrastructure

Reusable local AI platform for healthcare simulation projects.

## Components

- Ollama
- Open WebUI
- Langflow
- ChromaDB

## Start

docker compose up -d

## Stop

docker compose down

## Services

Open WebUI:
http://localhost:8080

Ollama:
http://localhost:11434

Langflow:
http://localhost:7860

ChromaDB:
http://localhost:8000
